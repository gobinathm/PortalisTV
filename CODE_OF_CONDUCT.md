# Code of Conduct

Portalis TV follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the project. Harassment, insults, discriminatory language and personal attacks are not tolerated in issues, pull requests, discussions or any other project space.

## Reporting
Report unacceptable behavior privately to the maintainers through the contact on the maintainer's GitHub profile. Reports are handled confidentially.

## Enforcement
Maintainers may edit or remove comments, lock threads, and temporarily or permanently ban contributors who violate this code, following the enforcement guidelines of the Contributor Covenant.
